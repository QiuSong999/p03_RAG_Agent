# 企业规章制度知识库

## 一、考勤管理制度

1. 公司标准工作时间为周一至周五，上午 9:00 至 12:00，下午 13:00 至 18:00。
2. 员工应按规定时间上下班。因特殊情况无法按时到岗的，应及时向直属主管说明原因。
3. 员工因个人原因迟到或早退，应按照公司考勤管理规定登记。具体处理方式由人力资源部门依据公司制度执行。
4. 员工因公外出时，应提前向直属主管报备，并按照公司要求记录外出时间和事由。

## 二、请假管理制度

1. 员工请假前应提交请假申请，说明请假类型、起止时间和请假原因。
2. 请假申请原则上应提前提交。遇到突发疾病等紧急情况时，应及时通知直属主管，并在条件允许后补办申请手续。
3. 一天以内的事假或年假，由直属主管审批。
4. 连续请假超过一天的，应由直属主管审核，并提交部门负责人审批。
5. 病假申请应根据公司要求提供相应的医疗证明材料。
6. 请假获批后，员工应做好工作交接。未经批准，不应自行认定请假已经生效。

## 三、费用报销制度

1. 员工申请费用报销时，应提交真实、完整的费用明细及合法有效的发票或其他规定凭证。
2. 报销申请应注明费用发生日期、费用类别、金额和用途。
3. 因公产生的交通费、住宿费和业务招待费，应符合公司费用管理要求。
4. 员工应通过公司指定的报销系统提交申请，并根据流程完成审批。
5. 报销材料不完整或费用用途不明确时，审批人员可以要求补充材料。
6. 未经批准的个人消费不得直接认定为可报销费用。

## 四、出差管理制度

1. 员工因工作需要出差，应提前提交出差申请，说明出差目的地、时间、事由及预计费用。
2. 出差申请应经直属主管审批；涉及额外预算或特殊安排时，还应按公司规定提交相应负责人审批。
3. 员工应优先选择符合公司差旅标准的交通和住宿方案。
4. 出差期间发生的合理公务费用，应保留有效凭证，并按照费用报销流程提交。
5. 出差结束后，员工应及时提交出差总结，并完成相关费用报销手续。

## 五、办公设备与信息安全制度

1. 公司电脑、办公设备及内部账号主要用于工作相关活动。
2. 员工不得擅自向无关人员披露公司内部资料、客户信息或账号凭据。
3. 员工发现设备遗失、账号异常或疑似信息泄露时，应及时向 IT 部门或直属主管报告。
4. 员工离职或岗位调整时，应按照公司要求归还设备，并完成账号权限和工作资料交接。

## 六、制度咨询与解释

1. 员工对考勤、请假、报销或出差制度存在疑问时，可以向直属主管或人力资源部门咨询。
2. 涉及信息安全、设备故障或账号权限的问题，可以向 IT 部门咨询。
3. 本知识库用于制度查询与辅助说明。如果某项具体规定未在资料中明确列出，助手应说明资料中没有相关信息，不得自行编造审批权限、金额上限、处罚标准或其他制度条款。
